## Расширения сверх презентации

- Лекция 1 подробнее разводит MCP с task spec, skills, subagents, `CODEBASE_INVENTORY.md` и `API_MAP.md`.
- Лекция 2 добавляет сценарии Commerce OS, фиксацию решения в `TASK_SPEC.md` и fallback при недоступном MCP.
- Лекция 3 добавляет полную карту восьми категорий, таблицу read-only/write tools и MCP-карту Workflow Kit.
- Лекция 4 добавляет учебную схему `mcp/issue-tracker.json`, фактический `.mcp.json`, OAuth-вход и CLI-диагностику.
- Лекция 5 добавляет риск-модель issue-tracker, permission-правила, лимиты вывода и двойную проверку MCP из плагина.
- Практика добавляет безопасные рамки, fallback на локальные фикстуры и требование честно помечать симуляцию.
- Контрольные вопросы связывают все пять лекций с презентацией и практикой.

## Остаточные ограничения

- Точные команды `claude mcp ...`, имена пакетов, поля `.mcp.json` и лимиты токенов зависят от версии Claude Code.
- Google Docs MCP-сервер в практике выбран условно; используйте доверенный сервер и проверяйте tools через `/mcp`.
- Внешние сервисы Firecrawl/Google Docs могут требовать тестовых аккаунтов и токенов; в практике есть fallback на локальные фикстуры.
- `MAX_MCP_OUTPUT_TOKENS` и порог предупреждения — ориентиры, а не гарантированные константы.
- Презентация остаётся источником верхнего уровня; при её обновлении матрицу нужно пересобрать.
