## Остаточные ограничения

- Нумерация локальной папки `lecture1` соответствует URL `lecture01`; на странице JavaRush лекция обозначена как «0 лекция».
- В презентации вебинара 4 есть блоки уровня 8, которых пока нет в виде отдельных лекций: runtime evidence, subagents и docs-as-code.
- Уровень 8 в конспектах пока не начат.
- Точные команды и поведение Claude Code могут зависеть от версии инструмента.

## Итог

Лекции 1–5 уровня 7, лекция 1 уровня 8 и capstone-практика покрывают свою часть материалов. Презентация вебинара 4 в целом пока не покрыта: для уровня 8 нужны отдельные лекции по runtime evidence, subagents и документации.
