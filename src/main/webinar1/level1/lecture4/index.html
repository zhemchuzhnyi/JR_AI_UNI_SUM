Команды запуска и команды в сессии

Claude Code

1 уровень · 4 лекция
У Claude Code есть два слоя команд: команды запуска, которые задают, как открыть CLI, и команды внутри сессии, которые управляют уже открытым разговором. Команда может быть правильной, но оказаться введённой не в тот слой.

Два слоя управления

Терминал / shell
  └─ запуск: claude ...
       └─ открытая сессия Claude Code
            └─ команды сессии: /help, /status, /clear, /compact ...

До открытия сессии — shell

В обычном терминале (Terminal, iTerm, PowerShell, Git Bash, WSL) выбираются папка проекта, способ запуска, возобновление и параметры вроде режима разрешений или worktree.

После запуска — активная сессия

Slash-команды управляют текущим разговором: состоянием, историей, контекстом, разрешениями и проверкой изменений. Они не запускают новый CLI.

Если Claude Code ещё не открыт — выбирайте команду запуска. Если открыт диалог — управляйте сессией.

Команды запуска

Откройте сессию в проекте Commerce OS:

cd ~/projects/commerce-os
claude

Другие варианты запуска — это тоже внешний слой:

claude -p "Кратко опиши структуру проекта"  # одноразовый запрос
claude -c                                     # продолжить предыдущую сессию
claude --permission-mode plan                 # пример режима на старте
claude --worktree ../commerce-os-exp          # пример отдельного worktree

Названия флагов и режимов зависят от версии. Проверяйте их через claude --help и актуальную документацию. Флаг запуска нельзя добавить задним числом к уже открытому разговору.

Команды внутри сессии

Slash-команды вводятся в открытой сессии. Они работают с её текущим контекстом и состоянием:

  • /help — локальная справка о командах вашей версии.
  • /status, /doctor — состояние и диагностика.
  • /context — что занимает контекст сессии.
  • /compact, /clear — сжать или очистить историю текущего разговора.
  • /diff — просмотреть изменения в коде.
  • /permissions, /review — работа с разрешениями или проверкой в рамках текущей сессии.
  • /rewind — восстановить состояние сессии, а не перезапустить CLI.
  • /exit — выйти из сессии.

/help — источник справки для той версии, которая запущена у вас. Если команда вызывает ошибку в обычном shell, вероятно, она предназначена для сессии.

Esc прерывает текущее действие агента: Claude останавливается и ждёт уточнения. Двойной Esc — перемотка истории разговора (rewind); случайно открывшееся меню закрывается тем же Esc.

Полезное упражнение первого дня: попросить Claude создать в проекте commands.md — шпаргалку по популярным командам: что делает каждая и когда её применять. Это заодно первый наглядный пример того, как агент создаёт и редактирует файлы. Разницу между /clear и /compact тоже можно просто спросить у Claude — он охотно объясняет собственные команды.

Как выбрать нужный слой

Выбирайте слой запуска, если нужно

  • открыть Claude в проекте;
  • выполнить одноразовый запрос;
  • продолжить прошлую сессию;
  • задать режим или отдельный worktree.

Выбирайте команды сессии, если нужно

  • проверить статус и окружение;
  • очистить или сжать историю;
  • посмотреть контекст или diff;
  • управлять уже начатой работой.

Например, /compact в shell введён не по адресу: он предназначен для текущей сессии. И наоборот, запускной флаг нельзя применить к уже открытому разговору — нужно запустить новую сессию с нужными параметрами.

Сценарий в Commerce OS

  1. Перейдите в папку проекта и запустите claude.
  2. В сессии проверьте /status и /doctor.
  3. После работы с файлами при необходимости проверьте /context, затем используйте /compact.
  4. Посмотрите изменения командой /diff.
  5. Для отдельного короткого запроса выйдите во внешний слой и запустите новый одноразовый вызов, например claude -p "Кратко опиши текущие изменения".

В одном рабочем процессе можно переключаться между слоями; важно понимать, в какой момент и где вводить команду.

Если нужно не просто очистить разговор, а сменить способ работы — например, открыть отдельный worktree для эксперимента, — /clear не поможет: он относится к текущей сессии, нужен новый запуск с нужными параметрами. А если вы уже в нужной сессии и просто теряетесь в накопленном диалоге, перезапускать ничего не надо — достаточно /compact или /clear.

Запоминайте логику, а не список команд

Имена команд и флаги меняются между версиями. Запоминайте назначение: claude --help показывает варианты запуска, /help — команды активной сессии, claude --version — текущую версию, официальная документация — актуальные детали.

Контрольный вопрос: «Я меняю способ запуска или управляю уже начатым разговором?»

Практика (15–25 минут)

Цель: Разделить команды запуска и команды сессии и собрать личную шпаргалку.

Что сделать

  1. В обычном shell выполните claude --help и выпишите три команды запуска.
  2. В открытой сессии выполните /help, /status и /context; выпишите три slash-команды и их назначение.
  3. Попросите Claude создать commands.md с таблицей из шести команд: три launch и три session, с колонками «что делает» и «когда использовать».
  4. Проверьте commands.md и объясните разницу между /clear и /compact. При желании проверьте Esc на длинном ответе.

Проверка

  • В commands.md есть две группы команд.
  • Вы можете определить, в каком слое вводится команда.
  • Вы объясняете, что делает Esc и чем /clear отличается от /compact.
Итог: команды запуска открывают сессию и задают условия её старта; команды внутри сессии управляют текущим разговором. Сначала определите нужный момент — потом выбирайте команду.
