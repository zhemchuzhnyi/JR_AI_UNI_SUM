САММАРИ ЛЕКЦИИ 4
Команды запуска и команды в сессии — Claude Code, 1 уровень

Главная идея: команды Claude Code относятся к двум разным слоям. Команды запуска вводятся во внешнем shell и определяют, как открыть CLI. Slash-команды вводятся уже в открытой сессии и управляют текущим разговором. Команда может быть правильной, но оказаться введённой не в тот слой.

1. Слой запуска — до сессии
В обычном терминале (Terminal, iTerm, PowerShell, Git Bash, WSL) выберите проект и способ запуска:

  cd ~/projects/commerce-os
  claude

Примеры других вариантов запуска:

  claude -p "Кратко опиши структуру проекта"  # одноразовый запрос
  claude -c                                     # продолжить предыдущую сессию
  claude --permission-mode plan                 # пример режима на старте
  claude --worktree ../commerce-os-exp          # пример отдельного worktree

Флаги и режимы могут меняться между версиями. Проверяйте их через claude --help и актуальную документацию. Параметры запуска задаются до старта сессии; их нельзя добавить задним числом в уже открытый разговор.

2. Команды внутри сессии
Slash-команды работают с текущей открытой сессией:

• /help — справка по командам именно вашей версии.
• /status и /doctor — состояние сессии и диагностика среды.
• /context — чем заполнен контекст.
• /compact — сжать историю; /clear — очистить диалог.
• /diff — посмотреть изменения кода.
• /permissions и /review — разрешения и проверка в текущей сессии.
• /rewind — восстановить состояние сессии, не перезапустить CLI.
• /exit — выйти из сессии.

Если написать /compact в обычном shell, команда введена не в том слое. А флаг запуска нельзя применить к уже работающей сессии.

**Esc** прерывает текущее действие агента: Claude останавливается и ждёт уточнения. Двойной Esc — перемотка истории разговора (rewind); случайно открывшееся меню закрывается тем же Esc.

Полезное упражнение первого дня: попросить Claude создать в проекте `commands.md` — шпаргалку по популярным командам: что делает каждая и когда её применять. Это заодно первый наглядный пример того, как агент создаёт и редактирует файлы. Разницу между `/clear` и `/compact` тоже можно просто спросить у Claude — он охотно объясняет собственные команды.

3. Быстрый выбор слоя
Если Claude Code ещё не открыт — нужна команда запуска. Если уже открыт диалог — используйте команду сессии.

Слой запуска нужен, чтобы открыть Claude в проекте, выполнить разовый запрос, продолжить прошлую сессию или задать стартовые параметры. Команды сессии нужны, чтобы проверять статус, чистить или сжимать историю, смотреть контекст и diff и управлять текущей работой.

4. Сценарий Commerce OS
Запустите claude из каталога проекта, проверьте /status и /doctor, поработайте с файлами, при необходимости проверьте /context и примените /compact. Просмотрите изменения через /diff. Для отдельного краткого запроса выйдите во внешний слой и запустите одноразовую команду, например:

  claude -p "Кратко опиши текущие изменения"

За один рабочий день нормально несколько раз переходить между слоями. Важно каждый раз понимать, меняете ли вы способ запуска или управляете уже открытым разговором.

Отдельный нюанс: если нужно не просто очистить разговор, а сменить способ работы — например, открыть отдельный worktree для эксперимента, — /clear не поможет, потому что относится к текущей сессии: нужен новый запуск с нужными параметрами. А если вы уже в нужной сессии и просто теряетесь в накопленном диалоге, перезапускать ничего не нужно — достаточно /compact или /clear, в зависимости от ситуации.

5. Что запомнить
Не заучивайте перечень команд: версии могут менять имена и флаги. Запоминайте назначение слоя. Для команд запуска используйте claude --help, для команд текущей сессии — /help, текущую версию смотрите через claude --version, детали сверяйте с актуальной документацией.

## Практика (15–25 минут)

**Цель:** Разделить команды запуска и команды сессии и собрать личную шпаргалку.

**Что сделать:**
1. В обычном shell выполните `claude --help` и выпишите три команды запуска.
2. В открытой сессии выполните `/help`, `/status` и `/context`; выпишите три slash-команды и их назначение.
3. Попросите Claude создать `commands.md` с таблицей из шести команд: три launch и три session, с колонками «что делает» и «когда использовать».
4. Проверьте `commands.md` и объясните разницу между `/clear` и `/compact`. При желании проверьте Esc на длинном ответе.

**Проверка:**
- В `commands.md` есть две группы команд.
- Вы можете определить, в каком слое вводится команда.
- Вы объясняете, что делает Esc и чем `/clear` отличается от `/compact`.
