# JR_AI_UNI_SUM

Учебные конспекты курса **Claude Code** от JavaRush: вебинары → уровни → лекции.

Для каждой лекции есть текстовый конспект `summary.txt` и HTML-версия `index.html`. В конце каждой лекции — короткая практика на 15–25 минут. Отдельно лежат практики вебинаров и контрольные вопросы по уровням.

**Сайт:** https://zhemchuzhnyi.github.io/JR_AI_UNI_SUM/

## Что внутри

- **Вебинар 1** — уровни 1–2, 10 лекций, практика вебинара, 30 контрольных вопросов.
- **Вебинар 2** — уровень 3 (5 лекций), уровень 4 (5 лекций), практики «калькулятор» и «симуляции», контрольные вопросы уровней 3 и 4.
- **Вебинар 3** — уровень 5, лекции 1–5: operational model, context selection, context budget, context pollution, session lifecycle; 20 контрольных вопросов. Уровень 6 — лекции 1–5: длинные задачи, checkpoints/rewind, Git-first recovery, worktree, handoff и fresh reviewer; 20 контрольных вопросов. Практика вебинара — справочник локалей.
- **Вебинар 4** — уровень 7, лекции 1–5: discovery, evidence-based Q&A, `CODEBASE_INVENTORY.md`, dependency map и runtime flow; уровень 8, лекции 1–5: API_MAP, runtime evidence, subagents, AI-assisted documentation и docs-as-code review; отдельная практика «Haiku 50».
- **Вебинар 5** — уровень 9, лекции 1–2: extension taxonomy; slash-команды, built-in commands, bundled и custom skills.

## Практики

- В конце каждой лекции — короткое упражнение с целью, шагами и самопроверкой.
- Для Git, permissions и работы с секретами используются только учебные репозитории и фейковые данные.
- Практики вебинаров — отдельные capstone-задания, они не заменяют практику в конце лекции.
